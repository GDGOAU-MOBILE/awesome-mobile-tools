# Awesome Mobile Dev Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of mobile apps and tools that help developers code, manage servers, use AI coding agents, debug applications, and handle DevOps workflows on the go.

Maintained by the GDG OAU Mobile Development community.

Whether you're coding from your phone, managing production servers, reviewing pull requests, or running AI coding agents remotely, this list helps you find the right tools for your workflow.

**Platforms:** iOS · Android · Cross-platform

**Note:** This list includes both open-source and proprietary tools. Open-source projects are marked with `Open Source`. Platform availability and licensing should be verified on the official project pages.

## SSH Clients and Terminals

Connect to remote servers, execute commands, manage files, and maintain infrastructure from your phone.

- [Onepilot](https://onepilotapp.com) - Mobile-first development environment for managing remote coding agents and servers. Check the official site for current features and platform availability.
- [Termius](https://termius.com) - Cross-platform SSH client with server management, terminal access, and SFTP.
- [Blink Shell](https://blink.sh) - Professional terminal for iOS with SSH, Mosh, and remote development workflows.
- [Prompt](https://panic.com/prompt/) - SSH terminal client for iOS from Panic.
- [JuiceSSH](https://juicessh.com) - SSH client for Android with connection management and plugin support.
- [Termux](https://termux.dev) - Terminal emulator and Linux environment for Android. `Open Source`
- [a-Shell](https://holzschu.github.io/a-Shell_iOS/) - Local Unix shell environment for iOS. `Open Source`
- [ConnectBot](https://connectbot.org) - SSH client for Android. `Open Source`
- [Shelly](https://apps.apple.com/us/app/shelly-ssh-client/id989642999) - SSH terminal client for iOS.

## AI Coding Agents and IDEs

Use AI to write code, debug issues, review changes, and manage development tasks from mobile devices or remote environments.

- [Onepilot](https://onepilotapp.com) - Mobile-focused workflow for remote AI coding agents. Check supported integrations on the official site.
- [GitHub Copilot](https://github.com/features/copilot) - AI coding assistant integrated into supported development environments and GitHub workflows.
- [Replit](https://replit.com) - Browser-based development environment with AI-assisted coding.
- [GitHub Mobile](https://github.com/mobile) - Access repositories, review pull requests, manage issues, and collaborate from mobile devices.
- [Claude](https://claude.ai) - AI assistant useful for code explanations, debugging, and development planning.
- [ChatGPT](https://chatgpt.com) - AI assistant for coding, troubleshooting, and technical research.

## Code Editors

Edit source files, make quick changes, and work with code directly from mobile devices.

### iOS

- [Textastic](https://www.textasticapp.com) - Code editor supporting syntax highlighting and remote file workflows.
- [Koder](https://koderapp.com) - Code editor for iOS with file management and remote connectivity features.
- [Buffer Editor](https://buffereditor.com) - Mobile code editor with development-oriented file and remote access features.

### Android

- [Acode](https://acode.app) - Code editor for Android with syntax highlighting, file management, and web development support.
- [Squircle CE](https://github.com/massivemadness/Squircle-CE) - Android code editor with syntax highlighting and programming-oriented features. `Open Source`
- [QuickEdit](https://play.google.com/store/apps/details?id=com.rhmsoft.edit) - Text and source code editor for Android.

## Remote Development

Develop using remote machines, cloud workspaces, or servers instead of relying entirely on local device resources.

- [code-server](https://github.com/coder/code-server) - Run VS Code in a browser on a remote machine. `Open Source`
- [Coder](https://github.com/coder/coder) - Provision and access development environments remotely. `Open Source`
- [GitHub Codespaces](https://github.com/features/codespaces) - Cloud-hosted development environments accessible through a browser.

## Networking and Debugging

Diagnose connectivity issues, inspect network behavior, and investigate problems across devices and servers.

- [Wireshark](https://github.com/wireshark/wireshark) - Network protocol analyzer. `Open Source`
- [HTTP Toolkit](https://github.com/httptoolkit/httptoolkit) - Inspect, debug, and troubleshoot HTTP(S) traffic. `Open Source`

- [Maestro](https://github.com/mobile-dev-inc/Maestro) - Automate mobile UI tests using readable flow definitions. `Open Source`
- [Appium](https://github.com/appium/appium) - Automate native, hybrid, and mobile web application tests. `Open Source`
- [Appium Inspector](https://github.com/appium/appium-inspector) - Inspect mobile UI elements and debug automated tests. `Open Source`
- [Flutter DevTools](https://github.com/flutter/devtools) - Debug, inspect, and profile Flutter applications. `Open Source`
- [LeakCanary](https://github.com/square/leakcanary) - Detect memory leaks in Android applications. `Open Source`

## Password Managers and Secrets

Store credentials securely and reduce the risk of exposing secrets in mobile and remote development workflows.

- [Bitwarden](https://github.com/bitwarden) - Password manager with open-source components. `Open Source components`
- [KeePassDX](https://github.com/Kunzisoft/KeePassDX) - Open-source password manager for Android. `Open Source`
- [Proton Pass](https://proton.me/pass) - Password manager with support for secure credential storage.
- [1Password](https://1password.com) - Password management and developer-focused secrets workflows.

Never commit API keys, SSH private keys, passwords, or production credentials to a repository.

## Contributing

Contributions are welcome from mobile developers, backend engineers, DevOps practitioners, and open-source contributors.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request.

When adding a tool:

1. Make sure it is relevant to mobile development or mobile-based developer workflows.
2. Link to the official project, repository, or product page.
3. Provide a concise and accurate description.
4. Identify supported platforms where known.
5. Mark open-source projects accurately and link to their source repositories.
6. Check whether the tool is still maintained or document its maintenance status.
7. Avoid duplicate entries and promotional descriptions.

### Entry Format

`- [Tool Name](official-url) - Brief description. Platform tags where useful.`
