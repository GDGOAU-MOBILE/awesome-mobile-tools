# Awesome Mobile Tools

A curated collection of open-source tools that help mobile developers build, debug, test, inspect, and ship better applications.

Maintained by the GDG OAU Mobile Development community.

Whether you're building Android or iOS applications, working with Flutter or React Native, or exploring mobile engineering, this list helps you discover tools that make development easier.

## Device Management

Tools for connecting to, controlling, and interacting with physical mobile devices.

- [scrcpy](https://github.com/Genymobile/scrcpy) - Display and control Android devices from a computer over USB or TCP/IP.

## Debugging and Inspection

Tools that help developers understand application behavior and investigate problems.

- [Flutter DevTools](https://github.com/flutter/devtools) - Debugging and performance tools for Flutter applications.
- [Appium Inspector](https://github.com/appium/appium-inspector) - Inspect application screens and UI elements for automated testing.

## UI Testing

Tools for automating user interactions and testing mobile application behavior.

- [Maestro](https://github.com/mobile-dev-inc/Maestro) - Automate mobile application UI tests using readable test flows.
- [Appium](https://github.com/appium/appium) - Automate native, hybrid, and mobile web application testing.

## Network Debugging

Tools for inspecting network traffic and troubleshooting API integrations.

- [HTTP Toolkit](https://github.com/httptoolkit/httptoolkit) - Inspect and debug HTTP(S) traffic.

## Performance Profiling

Tools for investigating application performance, memory usage, and resource consumption.

- [Flutter DevTools](https://github.com/flutter/devtools) - Profile Flutter applications and investigate performance issues.

## Screenshots and Recording

Tools for capturing application screens, recording interactions, and preparing visual evidence for debugging or documentation.

- [scrcpy](https://github.com/Genymobile/scrcpy) - Mirror Android screens and record device activity.

## Build and Release

Tools that automate mobile application builds, signing workflows, and releases.

- [fastlane](https://github.com/fastlane/fastlane) - Automate mobile development and release workflows.

## App Distribution

Tools and services that help developers distribute application builds to testers and collaborators.

- Contributions welcome.

## Security and Analysis

Tools for examining mobile application packages, reviewing application behavior, and identifying potential security issues.

- Contributions welcome.

## Contributing

Contributions are welcome from mobile developers of all experience levels.

Before submitting a tool, make sure it:

1. Solves a real problem in mobile application development.
2. Is open source and has a publicly accessible repository.
3. Has a clear README and installation or usage instructions.
4. Is reasonably maintained or remains useful for a clearly documented purpose.
5. Is placed in the most relevant category.
6. Has a concise description explaining what it does.

### Adding a Tool

1. Check whether the tool is already listed.
2. Open an issue if you want to suggest a new category or discuss a tool.
3. Submit a pull request with the tool in the appropriate section.
4. Include the official repository link and a short, factual description.

Please keep entries concise and avoid promotional descriptions.

### Entry Format

`- [Tool Name](official-repository-url) - A concise description of what the tool does.`
